# cocos-job-roadmap
第一阶段（1-8 周）基础扎实期
Week 1-2：TypeScript + JS 核心
任务：
TS 类型系统、泛型、接口、装饰器、模块化
JS 事件循环、闭包、原型链、this
产出：
手写一个小型事件总线 + 资源加载器（TS）
20 道 JS/TS 高频题笔记
Week 3-4：Cocos Creator 3.x 引擎核心
任务：
Node/Component 生命周期
Prefab、场景切换、输入系统、Tween、Animation
UI 系统（Widget/Layout/ScrollView）
产出：
做一个完整 UI Demo（大厅 + 弹窗 + 背包）
Week 5-6：数据结构算法 + 游戏数学
任务：
链表/栈队列/哈希/树、排序查找、复杂度
向量、坐标变换、碰撞检测、插值
产出：
30~40 道算法题（含讲解）
一个“角色移动+碰撞+相机跟随”Demo
Week 7-8：工程化基础
任务：
Git 分支协作、Commit 规范
ESLint/Prettier、目录规范
配置表驱动（JSON）
产出：
标准化项目脚手架（你后面3个项目都复用）
第二阶段（9-16 周）项目成型期（核心）
你需要 2 个主项目。

项目 A（Week 9-12）：2D 商业化休闲项目（单机）
建议题材：合成/消除/放置类任选其一。
必须包含：

模块：登录（模拟）、任务、背包、商城（模拟支付流程）、活动页
系统：红点、引导、弹窗管理、存档系统
技术点：对象池、资源分包、首屏加载优化
项目 A 交付物：

可执行包 + 演示视频（3-5 分钟）
架构图（模块分层）
性能报告（优化前后对比）
项目 B（Week 13-16）：联网玩法 Demo
建议题材：实时对战简化版（如 1v1 移动射击）或帧同步小游戏。
必须包含：

WebSocket 通信
心跳 + 断线重连
状态同步/指令同步（二选一）
战斗结算与回放（简化版）
项目 B 交付物：

客户端工程 + 协议文档
弱网测试说明（丢包/延迟处理）
Bug 复盘文档（至少 5 个典型问题）
第三阶段（17-22 周）进阶与优化期（拉开差距）
Week 17-19：性能优化专项
优化项：
DrawCall、节点数、纹理内存、GC 抖动
场景加载耗时、卡顿点定位
输出：
一份“性能压测报告”（这是面试王炸）
Week 20-21：渲染/3D/Shader 入门
至少完成其一：
3D 场景 + 摄像机系统 + 简单光照
Shader 特效（描边/溶解/流光）
输出：
1 个视觉效果 Demo + 原理说明
Week 22：工具化能力
写 1~2 个小工具：
资源重名检查、未引用资源扫描、配置表校验脚本
输出：
工具脚本仓库 + 使用说明
第四阶段（23-26 周）求职冲刺期
Week 23：简历与作品集定稿
简历只写“可量化结果”
例：将首屏加载从 4.2s 降至 2.1s
例：DrawCall 从 380 降至 140，低端机 FPS 从 38 提升到 55
准备：
GitHub 仓库整理
项目演示视频
在线文档主页（语雀/Notion均可）
Week 24-25：面试模拟
每天：
1 小时算法
1 小时引擎原理
1 小时项目复盘表达
重点练：
“你做过最难的优化是什么？”
“如果线上出现偶发卡死怎么排查？”
“你的架构如何支持新活动快速接入？”
Week 26：海投 + 定向投递
投递策略：
第一梯队：中大型游戏厂、出海公司
第二梯队：中小厂核心项目组（成长快）
每天复盘投递反馈，调整简历关键词。
